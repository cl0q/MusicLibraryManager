<task type="auto">
  <name>Task 1: Implement Chromaprint fingerprint generation and database storage</name>
  <files>
    src-tauri/src/fingerprint/mod.rs
    src-tauri/src/fingerprint/chromaprint.rs
    src-tauri/src/lib.rs
  </files>
  <action>
    1. Create `src-tauri/src/fingerprint/mod.rs`:
       - Declare submodules: pub mod chromaprint, pub mod acoustid, pub mod matcher
       - Re-export key functions: fingerprint_track, batch_fingerprint, lookup_acoustid, compare_fingerprints

    2. Create `src-tauri/src/fingerprint/chromaprint.rs`:
       a. `generate_fingerprint(samples: &[i16], sample_rate: u32, channels: u16) -> Option<Vec<u32>>`:
          - Create Fingerprinter with Configuration::preset_test2()
          - Call start(sample_rate, channels as u32), consume(samples), finish()
          - Return fingerprint() result

       b. `fingerprint_track(path: &Path) -> Result<(Vec<u32>, u32)>`:
          - Call audio::decoder::decode_to_pcm(path) to get samples
          - Call generate_fingerprint with the decoded samples
          - Return (fingerprint, duration_seconds) where duration = samples.len() / (sample_rate * channels)
          - Return error if fingerprint generation fails

       c. `save_fingerprint(conn: &Connection, track_id: i64, fingerprint: &[u32], duration_seconds: u32) -> Result<()>`:
          - Convert Vec<u32> to bytes (little-endian) for BLOB storage
          - INSERT OR REPLACE INTO fingerprints (track_id, fingerprint, duration_seconds)
          - Use rusqlite::params! with the byte slice

       d. `load_fingerprint(conn: &Connection, track_id: i64) -> Result<Option<Vec<u32>>>`:
          - SELECT fingerprint FROM fingerprints WHERE track_id = ?
          - Convert BLOB bytes back to Vec<u32> (little-endian)

       e. `get_unfingerprinted_tracks(conn: &Connection) -> Result<Vec<(i64, String)>>`:
          - SELECT t.id, t.original_path FROM tracks t LEFT JOIN fingerprints f ON t.id = f.track_id WHERE f.track_id IS NULL
          - Returns track IDs and paths that haven't been fingerprinted yet

       f. `batch_fingerprint(conn: &Connection, track_ids: &[(i64, String)]) -> Result<BatchFingerprintResult>`:
          - Process each track: decode -> fingerprint -> save
          - Collect successes and failures
          - Return BatchFingerprintResult { processed: usize, failed: Vec<(i64, String)> }
          - Use spawn_blocking pattern for CPU-intensive work (the caller will handle this)

    3. Add `pub mod fingerprint;` to lib.rs.

    4. Add unit tests:
       - test_fingerprint_blob_roundtrip: save_fingerprint then load_fingerprint, verify Vec<u32> matches
       - test_get_unfingerprinted_tracks: insert tracks, fingerprint some, verify only unfingerprinted returned
       - test_generate_fingerprint_with_silence: create a Vec<i16> of zeros (silence), verify fingerprint is generated (may be all zeros but should not panic)
  </action>
  <verify>
    Run `cargo test --manifest-path src-tauri/Cargo.toml -- fingerprint::chromaprint --nocapture` to verify tests pass.
  </verify>
  <done>
    Chromaprint module generates fingerprints from PCM samples, saves/loads to database as BLOB, identifies unfingerprinted tracks.
  </done>
</task>

<task type="auto">
  <name>Task 2: Implement AcoustID lookup and local fingerprint comparison</name>
  <files>
    src-tauri/src/fingerprint/acoustid.rs
    src-tauri/src/fingerprint/matcher.rs
  </files>
  <action>
    1. Create `src-tauri/src/fingerprint/acoustid.rs`:
       a. Define response types:
          - AcoustIdResponse { status: String, results: Vec<AcoustIdResult> }
          - AcoustIdResult { id: String, score: f64, recordings: Option<Vec<AcoustIdRecording>> }
          - AcoustIdRecording { id: String, title: Option<String>, artists: Option<Vec<AcoustIdArtist>> }
          - AcoustIdArtist { id: String, name: String }
          All derive Deserialize.

       b. `compress_fingerprint(raw: &[u32]) -> String`:
          - Use rusty_chromaprint's built-in compression if available, otherwise base64-encode the raw bytes
          - The AcoustID API accepts the compressed fingerprint string from fpcalc format

       c. `async fn lookup_acoustid(client: &reqwest::Client, api_key: &str, fingerprint: &[u32], duration: u32) -> Result<AcoustIdResponse>`:
          - Compress fingerprint to string format
          - POST to https://api.acoustid.org/v2/lookup with form params: client=api_key, duration, fingerprint, meta=recordings+releasegroups+compress
          - Parse JSON response into AcoustIdResponse
          - Return error with clear message if api_key is empty ("AcoustID API key not configured. Set ACOUSTID_API_KEY in .env")

       d. `save_acoustid_result(conn: &Connection, track_id: i64, acoustid: &str, mb_recording_id: Option<&str>) -> Result<()>`:
          - UPDATE fingerprints SET acoustid = ?, musicbrainz_recording_id = ? WHERE track_id = ?

       e. `get_api_key() -> Option<String>`:
          - Read ACOUSTID_API_KEY from environment (dotenvy already loads .env)
          - Return None if not set

    2. Create `src-tauri/src/fingerprint/matcher.rs`:
       a. `compare_fingerprints(fp1: &[u32], fp2: &[u32]) -> f64`:
          - Use rusty_chromaprint::match_fingerprints(fp1, fp2, &Configuration::preset_test2())
          - If matching segments found, compute a score from 0.0 to 1.0 based on the best segment score
          - Return 0.0 if no matching segments

       b. `are_duplicates(fp1: &[u32], fp2: &[u32], threshold: f64) -> bool`:
          - Call compare_fingerprints, return true if score >= threshold
          - Default threshold: 0.5 (conservative, can be tuned)

       c. `find_fingerprint_duplicates(conn: &Connection, track_id: i64) -> Result<Vec<(i64, f64)>>`:
          - Load fingerprint for track_id
          - Load all other fingerprints from database
          - Compare each pair, return Vec of (other_track_id, score) where score >= 0.3 (low threshold to catch candidates)
          - Sort by score descending
          - NOTE: For large libraries, this is O(n) per track. Acceptable for now; optimization (locality-sensitive hashing) can come later.

    3. Add unit tests:
       - test_compare_identical_fingerprints: same Vec<u32> should return score >= 0.9
       - test_compare_different_fingerprints: completely different data should return score < 0.3
       - test_are_duplicates_threshold: verify threshold logic
       - test_acoustid_api_key_missing: verify get_api_key returns None when env var not set
  </action>

  </verify>

  </done>
