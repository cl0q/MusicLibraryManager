    1. Create `src-tauri/src/artwork/mod.rs`:
       - Declare submodules: pub mod sources, pub mod cache, pub mod embed
       - Re-export: fetch_artwork_for_track, embed_artwork, batch_fetch_artwork, ArtworkCache

    2. Create `src-tauri/src/artwork/sources.rs`:
       a. `async fn search_release_group(client: &reqwest::Client, artist: &str, album: &str) -> Result<Option<String>>`:
          - Use musicbrainz_rs to search for release groups matching artist + album
          - ReleaseGroup::search(query).execute() — query format: "artist:{artist} AND releasegroup:{album}"
          - Return the MusicBrainz release group ID (MBID) of the best match, or None
          - Respect 1 req/sec rate limit (add 1 second delay with tokio::time::sleep)
          - If musicbrainz_rs search API is difficult, fall back to direct reqwest call to https://musicbrainz.org/ws/2/release-group?query=artist:{artist}+AND+releasegroup:{album}&fmt=json
          - Set User-Agent header: "MusicLibraryManager/0.1.0 (https://github.com/olli/musiclibrarymanager)" (MusicBrainz requires this)

       b. `async fn fetch_cover_art(client: &reqwest::Client, release_group_id: &str, size: u16) -> Result<Vec<u8>>`:
          - GET https://coverartarchive.org/release-group/{mbid}/front-{size} (size: 500 or 1200)
          - reqwest follows 307 redirects by default
          - Return image bytes on success
          - Return error with "No cover art available" on 404
          - Handle other HTTP errors appropriately

       c. `async fn fetch_artwork_for_track(client: &reqwest::Client, artist: &str, album: &str) -> Result<Option<(String, Vec<u8>, Vec<u8>)>>`:
          - Search for release group by artist + album
          - If found, fetch 500px (for embedding) and 1200px (for UI display) versions
          - Return Some((mbid, small_bytes, large_bytes)) on success, None if not found

    3. Create `src-tauri/src/artwork/cache.rs`:
       a. `ArtworkCache` struct:
          - cache_dir: PathBuf (stores cached artwork files)
          - new(cache_dir: PathBuf) -> Result<Self> — creates directory if needed

       b. `get_cached_path(&self, track_id: i64, size: &str) -> PathBuf`:
          - Returns cache_dir/{track_id}_{size}.jpg (e.g., cache_dir/42_500.jpg)

       c. `is_cached(&self, track_id: i64, size: &str) -> bool`:
          - Check if file exists at cached path

       d. `save_to_cache(&self, track_id: i64, size: &str, data: &[u8]) -> Result<PathBuf>`:
          - Write data to cache path, return the path

       e. `save_artwork_state(conn: &Connection, track_id: i64, artwork_path: &str, source: &str, mbid: Option<&str>, resolution: &str) -> Result<()>`:
          - INSERT OR REPLACE INTO artwork (track_id, artwork_path, source, musicbrainz_release_group_id, resolution)

       f. `get_tracks_without_artwork(conn: &Connection) -> Result<Vec<(i64, String, String)>>`:
          - SELECT t.id, t.artist, t.album FROM tracks t LEFT JOIN artwork a ON t.id = a.track_id WHERE a.track_id IS NULL
          - Returns tracks that don't have artwork records yet

       - test_get_tracks_without_artwork: insert tracks, add artwork for some, verify only missing returned
       - test_save_artwork_state_roundtrip: save and query artwork table

<task type="auto">
  <name>Task 2: Implement artwork embedding and batch processing</name>
  <files>

  <action>
    1. Create `src-tauri/src/artwork/embed.rs`:
       a. `fn has_embedded_artwork(path: &Path) -> Result<bool>`:
          - Use lofty::Probe::open(path)?.read()? to get tagged file
          - Check if primary tag has any Picture with PictureType::CoverFront
          - Return true if front cover exists

       b. `fn embed_artwork(audio_path: &Path, image_data: &[u8]) -> Result<()>`:
          - Open file with lofty::Probe::open
          - Get primary_tag_mut
          - Create Picture from image bytes via Picture::from_reader(&mut Cursor::new(image_data))
          - Set pic_type to PictureType::CoverFront
          - Remove existing CoverFront pictures first (tag.remove_picture_type)
          - Push new picture
          - Save with WriteOptions::default()
          - Return error if no primary tag exists

       c. `fn extract_embedded_artwork(path: &Path) -> Result<Option<Vec<u8>>>`:
          - Open file, find first Picture with PictureType::CoverFront
          - Return Some(data.to_vec()) if found, None otherwise
          - Useful for caching artwork from files that already have it embedded

       d. `fn resize_artwork(image_data: &[u8], max_dimension: u32) -> Result<Vec<u8>>`:
          - Use image crate to decode bytes
          - If either dimension > max_dimension, resize maintaining aspect ratio (image::imageops::FilterType::Lanczos3)
          - Re-encode as JPEG with quality 85
          - Return resized bytes
          - If already smaller than max_dimension, return original data unchanged

    2. Update `src-tauri/src/artwork/mod.rs`:
       a. Add `batch_fetch_artwork` function:
          ```rust
          pub async fn batch_fetch_artwork(
              conn: &Connection,
              cache: &ArtworkCache,
              client: &reqwest::Client,
              track_ids: &[(i64, String, String)], // (id, artist, album)
          ) -> Result<BatchArtworkResult>
          ```
          - For each track: check if already cached, if not fetch from MusicBrainz/CAA
          - Save 500px to cache for embedding, 1200px to cache for UI display
          - If track already has embedded artwork, extract it to cache instead of fetching
          - Record in database via save_artwork_state
          - Respect 1 req/sec MusicBrainz rate limit (tokio::time::sleep between requests)
          - Return BatchArtworkResult { fetched: usize, already_cached: usize, not_found: usize, failed: Vec<(i64, String)> }

       - test_resize_artwork: create a small JPEG, verify resize doesn't crash for valid image data
       - test_extract_embedded_returns_none: verify returns None for file without artwork (or returns error for non-audio file)
