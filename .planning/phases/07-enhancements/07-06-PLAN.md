    1. Create `src-tauri/src/commands/enhancements.rs` with the following Tauri commands:

       a. `#[tauri::command] async fn fingerprint_library_cmd(app: tauri::AppHandle) -> Result<serde_json::Value, String>`:
          - Use spawn_blocking + block_on pattern (matching existing sync commands)
          - Get database connection, call fingerprint::chromaprint::get_unfingerprinted_tracks
          - Emit "fingerprint:started" event with { total: count }
          - For each track: fingerprint_track, save_fingerprint, emit "fingerprint:progress" with { current, total, track_id }
          - Add 0ms delay between tracks (CPU-bound, not rate-limited)
          - Emit "fingerprint:completed" with { processed, failed }
          - Return JSON summary

       b. `#[tauri::command] async fn fetch_artwork_cmd(app: tauri::AppHandle) -> Result<serde_json::Value, String>`:
          - Get tracks without artwork via artwork::cache::get_tracks_without_artwork
          - Emit "artwork:started" event
          - For each track: fetch from MusicBrainz/CAA, cache, emit "artwork:progress"
          - Add 1000ms delay between MusicBrainz requests (rate limit)
          - Emit "artwork:completed"
          - Return summary

       c. `#[tauri::command] async fn analyze_replaygain_cmd(app: tauri::AppHandle) -> Result<serde_json::Value, String>`:
          - Get unanalyzed tracks via replaygain::analyzer::get_unanalyzed_tracks
          - Emit "replaygain:started" event
          - For each track: analyze_track, save_track_gain, emit "replaygain:progress"
          - Emit "replaygain:completed"
          - Return summary

       d. `#[tauri::command] async fn deep_scan_cmd(app: tauri::AppHandle) -> Result<serde_json::Value, String>`:
          - Call dedup::fingerprint::deep_scan_library
          - Emit "deepscan:started", "deepscan:progress", "deepscan:completed" events
          - Return DeepScanResult as JSON

       e. `#[tauri::command] async fn get_review_queue_cmd(status: Option<String>) -> Result<serde_json::Value, String>`:
          - Call dedup::fingerprint::get_review_queue with optional status filter
          - Return as JSON array

       f. `#[tauri::command] async fn resolve_review_item_cmd(review_id: i64, action: String) -> Result<(), String>`:
          - Call dedup::fingerprint::resolve_review_item
          - Validate action is one of: "approved", "rejected", "dismissed"

       g. `#[tauri::command] async fn get_review_queue_count_cmd() -> Result<i64, String>`:
          - SELECT COUNT(*) FROM review_queue WHERE status = 'pending'
          - Used by sidebar badge
