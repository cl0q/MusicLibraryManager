  <action>
    1. Create `src-tauri/src/replaygain/mod.rs`:
       - Declare submodules: pub mod analyzer, pub mod tagger
       - Re-export: analyze_track, analyze_album, batch_analyze, write_gain_tags
       - Define GainResult struct: { track_gain: f64, track_peak: f64 }
       - Define AlbumGainResult struct: { album_gain: f64, album_peak: f64, tracks: Vec<(i64, GainResult)> }

    2. Create `src-tauri/src/replaygain/analyzer.rs`:
       a. `fn analyze_loudness(samples: &[i16], sample_rate: u32, channels: u16) -> Result<(f64, f64)>`:
          - Create EbuR128 with Mode::I | Mode::TRUE_PEAK, channels, sample_rate
          - Call add_frames_i16(samples) — interleaved format from our decoder
          - Get loudness_global() for integrated loudness
          - Get max true_peak() across all channels
          - Compute gain: -18.0 - loudness (ReplayGain 2.0 reference is -18 LUFS)
          - Return (gain_db, max_peak_linear)

       b. `fn analyze_track(path: &Path) -> Result<GainResult>`:
          - Call audio::decoder::decode_to_pcm(path)
          - Call analyze_loudness with the decoded samples
          - Return GainResult { track_gain, track_peak }

       c. `fn analyze_album(tracks: &[(i64, &Path)]) -> Result<AlbumGainResult>`:
          - For each track, decode and analyze individually for track gain
          - For album gain: use ebur128's ability to analyze multiple files
            - Create one EbuR128 instance, call add_frames_i16 for all tracks sequentially
            - Or use loudness_global_multiple() if available
            - Fallback: decode all tracks, concatenate loudness from individual analyses, compute album-level loudness
          - Actually the cleanest approach: create separate EbuR128 per track for track gain, then use ebur128::loudness_global_multiple() with references to all analyzers
          - Return AlbumGainResult with album_gain, album_peak (max peak across all tracks), and per-track gain results

       d. `fn save_track_gain(conn: &Connection, track_id: i64, gain: &GainResult) -> Result<()>`:
          - INSERT OR REPLACE INTO replaygain (track_id, track_gain, track_peak)

       e. `fn save_album_gain(conn: &Connection, track_ids: &[i64], album_gain: f64, album_peak: f64) -> Result<()>`:
          - UPDATE replaygain SET album_gain = ?, album_peak = ? WHERE track_id IN (...)
          - Only updates album fields, preserving existing track gain values

       f. `fn get_unanalyzed_tracks(conn: &Connection) -> Result<Vec<(i64, String)>>`:
          - SELECT t.id, t.original_path FROM tracks t LEFT JOIN replaygain r ON t.id = r.track_id WHERE r.track_id IS NULL

       g. `fn get_track_gain(conn: &Connection, track_id: i64) -> Result<Option<GainResult>>`:
          - SELECT track_gain, track_peak FROM replaygain WHERE track_id = ?

       h. `fn batch_analyze(conn: &Connection, tracks: &[(i64, String)]) -> Result<BatchAnalyzeResult>`:
          - Process each track: decode -> analyze -> save
          - Return BatchAnalyzeResult { analyzed: usize, failed: Vec<(i64, String)> }

    3. Add `pub mod replaygain;` to lib.rs.

    4. Unit tests:
       - test_analyze_loudness_silence: feed silent samples (zeros), verify gain is a reasonable value (very high positive gain for silence, or handle -inf loudness as a special case)
       - test_analyze_loudness_full_scale: feed full-scale sine wave samples, verify gain is negative (louder than reference)
       - test_save_and_load_track_gain: save gain values, load them back, verify match
       - test_get_unanalyzed_tracks: insert tracks, analyze some, verify only unanalyzed returned
       - test_replaygain_reference_level: verify gain formula uses -18 LUFS reference (not -23)

    Note on silence handling: ebur128 may return -infinity for complete silence. Handle this by clamping to a reasonable value like +20.0 dB gain, or skipping analysis for silent tracks.

          - Open file with lofty::Probe::open(file_path)?.read()?
          - Get primary_tag_mut()
          - Write ItemKey::ReplayGainTrackGain with value "{:.2} dB" format (e.g., "-6.43 dB")
          - Write ItemKey::ReplayGainTrackPeak with value "{:.6}" format (e.g., "0.978465")
          - If album_gain/album_peak provided:
            - Write ItemKey::ReplayGainAlbumGain
            - Write ItemKey::ReplayGainAlbumPeak
          - Save with WriteOptions::default()
          - Use TagItem::new(ItemKey, ItemValue::Text(value)) pattern
          - Return clear error if no primary tag exists

       b. `fn read_gain_tags(file_path: &Path) -> Result<Option<(f64, f64)>>`:
          - Read ReplayGainTrackGain and ReplayGainTrackPeak from file
          - Parse the string values back to f64
          - Return None if tags don't exist

    2. Integrate with sync pipeline in `src-tauri/src/sync/progress.rs`:
       - In `execute_sync()`, after the successful file link/copy step (after `cache.link_to_profile`), add ReplayGain tag writing:
         ```rust
         // Write ReplayGain tags to synced copy (library originals stay pristine)
         if let Ok(Some(gain)) = crate::replaygain::analyzer::get_track_gain(conn, file.track_id) {
             // Also try to get album gain
             let (album_gain, album_peak) = get_album_gain(conn, file.track_id);
             if let Err(e) = crate::replaygain::tagger::write_gain_tags(
                 &dest_path, gain.track_gain, gain.track_peak, album_gain, album_peak
             ) {
                 log::warn!("Failed to write ReplayGain tags for track {}: {}", file.track_id, e);
                 // Non-fatal: sync succeeds even if RG tagging fails
             }
         }
         ```
       - Add helper `fn get_album_gain(conn: &Connection, track_id: i64) -> (Option<f64>, Option<f64>)`:
         - SELECT album_gain, album_peak FROM replaygain WHERE track_id = ?
         - Return (None, None) if not found or not analyzed

       IMPORTANT: ReplayGain tag writing is best-effort during sync. If gain values haven't been calculated yet, skip silently. This is intentional: the user can analyze tracks separately, and the next sync will pick up the values.
