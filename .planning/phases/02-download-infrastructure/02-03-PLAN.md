<task type="auto">
  <name>Implement FFmpeg AAC transcoding wrapper</name>
  <files>src-tauri/src/transcode/ffmpeg.rs, src-tauri/src/transcode/mod.rs</files>
  <action>
Create `src-tauri/src/transcode/ffmpeg.rs` implementing:

**FfmpegConfig struct:**
- Fields:
  - `target_bitrate: u32` (default: 248_000 = 248kbps)
  - `encoder: String` (default: "libfdk_aac")
  - `fallback_encoder: String` (default: "aac" - native ffmpeg AAC if libfdk_aac unavailable)

**Functions:**
1. `fn check_libfdk_aac_available() -> Result<bool>`
   - Run `ffmpeg -encoders` and grep output for "fdk_aac"
   - Return true if found, false otherwise
   - Log warning if libfdk_aac not available: "libfdk_aac encoder not found, falling back to native AAC (lower quality)"

2. `async fn transcode_to_aac(input: &Path, output: &Path, config: &FfmpegConfig) -> Result<()>`
   - Check libfdk_aac availability first
   - Select encoder: libfdk_aac if available, else fallback to aac
   - Build ffmpeg command:
     - Input: `-i {input}`
     - Audio codec: `-c:a {encoder}`
     - Bitrate: `-b:a {target_bitrate}`
     - Output: `{output}`
   - Example: `ffmpeg -i input.flac -c:a libfdk_aac -b:a 248k output.m4a`
   - Spawn process with `tokio::process::Command`
   - Stream stderr for progress logging (ffmpeg writes progress to stderr)
   - Wait for completion, check exit code
   - Atomic write: transcode to temp file, rename to final path only on success
   - On failure: delete temp file, return error (original file preserved)

Reference RESEARCH.md "Code Examples: FFmpeg AAC Encoding with libfdk_aac" for command structure.
Reference RESEARCH.md "Pitfall 4: Forgetting libfdk_aac is Non-Free" for availability check rationale.

In `mod.rs`: Add `pub mod ffmpeg;` export.

Why libfdk_aac with fallback: User specified libfdk_aac for highest quality. Fallback to native AAC prevents hard failure if ffmpeg not compiled with libfdk_aac support.
  </action>

  <done>FFmpeg wrapper exists with libfdk_aac support and fallback, transcodes to 248kbps AAC</done>

In `src-tauri/src/transcode/mod.rs`, add orchestration function:

**TranscodeResult enum:**
- `Transcoded(PathBuf)` - AAC file created at path
- `Skipped(String)` - transcode skipped with reason (e.g., "Already lossy <248k")
- `Failed(String)` - transcode attempted but failed, original preserved

**Function:**
1. `async fn transcode_audio(input: &Path, output_dir: &Path) -> Result<TranscodeResult>`
   - Detect format: `let format = detect_format(input)?`
   - Decision logic:
     - If `format.is_lossless == true` (FLAC, ALAC, WAV):
       → Transcode to AAC
     - Else if `format.bitrate.unwrap_or(999_000) < 248_000`:
       → Skip transcode, return `Skipped("Already lossy <248kbps")`
     - Else if lossy but >= 248kbps:
       → Transcode to AAC (reduce file size for device sync)
   - Construct output path: `{output_dir}/{input_stem}.m4a`
   - Call `transcode_to_aac(input, output_path, &FfmpegConfig::default())`
   - On success: return `Transcoded(output_path)`
   - On error: return `Failed(error_message)` (original file preserved)

Reference RESEARCH.md "Pattern 3: Audio Format Detection Before Transcode" for decision tree.
Reference 02-CONTEXT.md decisions: "If source is already lossy and below 248kbps: keep original format, don't transcode (avoid quality loss)."

Add module exports:
```rust

pub mod ffmpeg;

pub use format::{detect_format, AudioFormat};
pub use ffmpeg::{transcode_to_aac, FfmpegConfig};

pub async fn transcode_audio(input: &Path, output_dir: &Path) -> Result<TranscodeResult> { ... }

pub enum TranscodeResult {
    Transcoded(PathBuf),
    Skipped(String),
    Failed(String),
}
```

Why preserve originals on failure: Transcode failures shouldn't trigger re-download. Keep FLAC, mark AAC as pending, retry transcode later.
