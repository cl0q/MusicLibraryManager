<task type="auto">
  <name>Create SQLite schema with normalized tables</name>
  <files>
    src/library/database.py
  </files>
  <action>
Create SQLite database schema following the research-recommended pattern from RESEARCH.md Pattern 2.

Tables to create:
1. **files** table: Store file tracking with reference-in-place model
   - id (INTEGER PRIMARY KEY)
   - original_path (TEXT UNIQUE NOT NULL) - where file actually lives
   - organized_path (TEXT NOT NULL) - Album Artist/Album/Track structure
   - is_soundcloud (BOOLEAN DEFAULT 0) - separate folder structure flag
   - imported_at (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)
   - last_synced (TIMESTAMP)

2. **metadata** table: Cache metadata for search indexing
   - id (INTEGER PRIMARY KEY)
   - file_id (INTEGER UNIQUE) - FK to files
   - artist (TEXT)
   - album_artist (TEXT) - key field for folder organization
   - album (TEXT)
   - title (TEXT)
   - genre (TEXT)
   - year (INTEGER)
   - bitrate (INTEGER) - for quality-based duplicate resolution
   - format (TEXT) - mp3, flac, aac (for quality hierarchy: lossless > lossy)
   - duration (INTEGER)
   - FOREIGN KEY(file_id) REFERENCES files(id) ON DELETE CASCADE

3. **duplicates** table: Track duplicate relationships
   - id (INTEGER PRIMARY KEY)
   - primary_file_id (INTEGER) - higher quality version FK
   - duplicate_file_id (INTEGER) - lower quality version FK
   - reason (TEXT) - "lower_bitrate", "worse_format", etc
   - reviewed (BOOLEAN DEFAULT 0)
   - FOREIGN KEY(primary_file_id) REFERENCES files(id)
   - FOREIGN KEY(duplicate_file_id) REFERENCES files(id)

4. **search_index** table: Track Whoosh indexing status
   - file_id (INTEGER PRIMARY KEY)
   - indexed_at (TIMESTAMP)
   - FOREIGN KEY(file_id) REFERENCES files(id) ON DELETE CASCADE

Create indexes on:
- metadata(artist, album_artist, album, title) for fast duplicate detection
- files(original_path) for existence checks

Include CRUD wrapper functions:
- save_file_record(original_path, organized_path, is_soundcloud, metadata_dict) -> file_id
- get_file_by_path(original_path) -> file_record or None
- get_all_files() -> list of file_records with metadata
- mark_as_duplicate(primary_file_id, duplicate_file_id, reason)
- get_duplicates(reviewed=False) -> list of duplicate pairs
- mark_duplicate_reviewed(duplicate_id)

Use context manager pattern for connection handling. Follow atomicity requirement (DL-05): wrap all writes in transactions.

<task type="auto">
  <name>Create configuration module for library paths</name>
  <files>
    src/core/config.py
  </files>
  <action>
Create configuration module managing library paths and settings.

Configuration fields:
- LIBRARY_ROOT: Path to external drive (Lexxar) for main library storage
- LIBRARY_DB_PATH: SQLite database location (default: LIBRARY_ROOT/library.db)
- SOUNDCLOUD_FOLDER: Separate folder for SoundCloud content (default: LIBRARY_ROOT/SoundCloud)
- ARCHIVE_FOLDER: Original files organized by Artist/Album/Track (default: LIBRARY_ROOT/Archive)
- DUPLICATES_FOLDER: Lower quality duplicates moved here for review (default: LIBRARY_ROOT/_duplicates)
- WHOOSH_INDEX_DIR: Full-text search index location (default: LIBRARY_ROOT/.index)
- SEARCH_FUZZY_THRESHOLD: RapidFuzz matching threshold (default: 80)
- SEARCH_DEBOUNCE_MS: Instant search debounce delay (default: 200)

Use environment variables with fallback defaults. Load config from .env file if present (python-dotenv).

Example structure:
```python
import os
from pathlib import Path
from dotenv import load_dotenv

load_dotenv()

LIBRARY_ROOT = Path(os.getenv("LIBRARY_ROOT", os.path.expanduser("~/Music/MusicLibrary")))
LIBRARY_DB_PATH = LIBRARY_ROOT / "library.db"
SOUNDCLOUD_FOLDER = LIBRARY_ROOT / "SoundCloud"
ARCHIVE_FOLDER = LIBRARY_ROOT / "Archive"
DUPLICATES_FOLDER = LIBRARY_ROOT / "_duplicates"
WHOOSH_INDEX_DIR = LIBRARY_ROOT / ".index"
SEARCH_FUZZY_THRESHOLD = int(os.getenv("SEARCH_FUZZY_THRESHOLD", "80"))
SEARCH_DEBOUNCE_MS = int(os.getenv("SEARCH_DEBOUNCE_MS", "200"))

# Ensure directories exist
for path in [LIBRARY_ROOT, SOUNDCLOUD_FOLDER, ARCHIVE_FOLDER, DUPLICATES_FOLDER, WHOOSH_INDEX_DIR]:
    path.mkdir(parents=True, exist_ok=True)
```
