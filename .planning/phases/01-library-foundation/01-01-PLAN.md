```rust
pub const SCHEMA_SQL: &str = "
CREATE TABLE IF NOT EXISTS tracks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    artist TEXT NOT NULL,
    album_artist TEXT NOT NULL,
    album TEXT NOT NULL,
    title TEXT NOT NULL,
    genre TEXT,
    year INTEGER,
    bitrate INTEGER,
    duration INTEGER,
    format TEXT NOT NULL,
    original_path TEXT NOT NULL UNIQUE,
    organized_path TEXT,
    is_duplicate INTEGER DEFAULT 0,
    date_added TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_artist ON tracks(artist);
CREATE INDEX IF NOT EXISTS idx_album ON tracks(album);
CREATE INDEX IF NOT EXISTS idx_title ON tracks(title);
CREATE INDEX IF NOT EXISTS idx_duplicate ON tracks(is_duplicate);
";
```

Implement connection manager pattern from RESEARCH.md Pattern 2 (Transactional Database Writes).

CRITICAL: rusqlite has `PRAGMA foreign_keys = OFF` by default. Must enforce per connection (Python Pitfall 1).

Create `connection.rs` with:
1. **get_connection(db_path: &Path) -> Result&lt;Connection&gt;**:
   - Opens or creates SQLite database at db_path
   - Executes `PRAGMA foreign_keys = ON` immediately after opening
   - Calls `initialize_schema(&conn)` to ensure tables exist
   - Returns connection

2. **Connection wrapper helper**:
   - Add `pub fn with_transaction&lt;F, T&gt;(conn: &Connection, f: F) -> Result&lt;T&gt; where F: FnOnce(&Transaction) -> Result&lt;T&gt;`
   - Creates transaction, calls closure, commits on Ok, rolls back on Err
   - Explicit `.commit()?` call (Python Pitfall 4: rollback on panic)

Use `thiserror` for error types:
```rust
#[derive(Debug, thiserror::Error)]
pub enum DatabaseError {
    #[error("SQLite error: {0}")]
    Sqlite(#[from] rusqlite::Error),
    #[error("Connection failed: {0}")]
    Connection(String),
}

pub type Result&lt;T&gt; = std::result::Result&lt;T, DatabaseError&gt;;
```

Add to mod.rs:
```rust
pub mod schema;
pub mod connection;

pub use connection::{get_connection, with_transaction, DatabaseError, Result};
pub use schema::initialize_schema;
```
