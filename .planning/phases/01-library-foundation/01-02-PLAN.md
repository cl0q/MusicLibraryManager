  <behavior>
Given metadata fields (album_artist, album, title) containing FAT32-invalid characters:
- Slashes: "AC/DC" -> "AC_DC"
- Colons: "Artist: The Best" -> "Artist_ The Best"
- Reserved chars (< > : " | ? *): replaced with underscore
- Leading/trailing dots/spaces: stripped
- Windows reserved names (CON, PRN, AUX, NUL, COM1-9, LPT1-9): prefixed with underscore
- Path length: truncate components if necessary (FAT32 path component limit ~255 chars)

Test cases:
1. Input: "AC/DC" -> Output: "AC_DC"
2. Input: "Artist: The Best" -> Output: "Artist_ The Best"
3. Input: "Song <2024>" -> Output: "Song _2024_"
4. Input: "CON" -> Output: "_CON"
5. Input: "The Beatles" -> Output: "The Beatles" (no change)
6. Input: "Very Long Album Name..." (300 chars) -> Output: truncated to 255 chars
7. Input: ".hidden" -> Output: "hidden" (leading dot stripped)

Full path construction:
- Input: album_artist="AC/DC", album="Back in Black", title="Thunderstruck"
- Output: "AC_DC/Back in Black/Thunderstruck.mp3"

Create src/library/sanitizer.py with minimal implementation using pathvalidate.

```python
from pathvalidate import sanitize_filename as pv_sanitize_filename
from pathlib import Path

def sanitize_filename(name: str, max_length: int = 255) -> str:
    """Sanitize single filename component for FAT32 compatibility."""
    if not name:
        return "unknown"

    # Use pathvalidate with FAT platform target
    sanitized = pv_sanitize_filename(name, platform="fat", replacement_text="_")

    # Strip leading dots/spaces
    sanitized = sanitized.lstrip(". ")

    # Handle Windows reserved names
    reserved = ["CON", "PRN", "AUX", "NUL"] + [f"COM{i}" for i in range(1, 10)] + [f"LPT{i}" for i in range(1, 10)]
    if sanitized.upper() in reserved:
        sanitized = f"_{sanitized}"

    # Truncate if too long
    if len(sanitized) > max_length:
        sanitized = sanitized[:max_length]

    return sanitized

def sanitize_path(album_artist: str, album: str, title: str, extension: str = ".mp3") -> str:
    """Build full organized path with sanitized components."""
    artist_safe = sanitize_filename(album_artist)
    album_safe = sanitize_filename(album)
    title_safe = sanitize_filename(title)

    return f"{artist_safe}/{album_safe}/{title_safe}{extension}"
```
