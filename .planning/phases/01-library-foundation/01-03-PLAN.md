Create metadata extraction module wrapping Mutagen for reading audio file metadata.

Follow RESEARCH.md Pattern 1 (Metadata-Driven File Organization) and Code Example (Reading ID3v2).

Function: extract_metadata(file_path: str) -> dict

Return dictionary with fields:
- artist (TPE1 frame for ID3v2, "artist" for Vorbis/APEv2)
- album_artist (TPE2 frame for ID3v2, "albumartist" for Vorbis/APEv2, fallback to artist)
- album (TALB frame for ID3v2, "album" for Vorbis/APEv2)
- title (TIT2 frame for ID3v2, "title" for Vorbis/APEv2)
- genre (TCON frame for ID3v2, "genre" for Vorbis/APEv2)
- year (TDRC frame for ID3v2, "date" for Vorbis/APEv2, extract year as integer)
- bitrate (audio.info.bitrate from Mutagen)
- format (determine from file extension: .mp3, .flac, .m4a, .aac)
- duration (audio.info.length in seconds)

Handle missing metadata gracefully:
- album_artist defaults to artist if missing, then "Various Artists" if both missing
- title defaults to filename without extension if missing
- album defaults to "Unknown Album" if missing
- genre, year can be None
- Log warning for missing critical fields (artist, title)

Handle unsupported formats:
- Use mutagen.File() which auto-detects format
- If mutagen.File() returns None, raise ValueError("Unsupported format")

Handle corrupted files:
- Wrap in try/except catching mutagen exceptions
- Re-raise as MetadataExtractionError with original file path

Example:
```python
import mutagen
from pathlib import Path

class MetadataExtractionError(Exception):
    """Raised when metadata extraction fails."""
    pass

def extract_metadata(file_path: str) -> dict:
    try:
        audio = mutagen.File(file_path)
        if audio is None:
            raise ValueError(f"Unsupported format: {file_path}")

        # Extract based on tag type
        if hasattr(audio, 'tags') and audio.tags:
            # ID3v2 (MP3)
            artist = audio.tags.get("TPE1", [None])[0] if "TPE1" in audio.tags else None
            album_artist = audio.tags.get("TPE2", [None])[0] if "TPE2" in audio.tags else None
            # ... (extract other fields)
        elif hasattr(audio, 'get'):
            # Vorbis/APEv2 (FLAC, OGG)
            artist = audio.get("artist", [None])[0]
            album_artist = audio.get("albumartist", [None])[0]
            # ... (extract other fields)

        # Fallbacks
        album_artist = album_artist or artist or "Various Artists"
        title = title or Path(file_path).stem
        album = album or "Unknown Album"

        # Audio info
        bitrate = getattr(audio.info, 'bitrate', 0)
        duration = getattr(audio.info, 'length', 0)
        format = Path(file_path).suffix.lstrip('.')

        return {
            "artist": artist,
            "album_artist": album_artist,
            "album": album,
            "title": title,
            "genre": genre,
            "year": year,
            "bitrate": bitrate,
            "format": format,
            "duration": int(duration)
        }
    except Exception as e:
        raise MetadataExtractionError(f"Failed to extract metadata from {file_path}: {e}")
```

Support formats: MP3 (ID3v2), FLAC (Vorbis), AAC/M4A (MP4), OGG (Vorbis).

Create atomic file operations module wrapping atomicwrites for DL-05 requirement (atomic operations).

Functions:
1. atomic_write_database(db_path: str, write_func: callable): Wrap database writes in atomic transaction
   - Use atomicwrites.atomic_write() with overwrite=True
   - Pass file handle to write_func
   - Commit on success, rollback on exception

2. safe_file_exists(file_path: str) -> bool: Check if file exists and is readable
   - Use Path.exists() and Path.is_file()
   - Handle permission errors gracefully

3. get_file_size(file_path: str) -> int: Get file size in bytes
   - Use Path.stat().st_size
   - Return 0 if file doesn't exist

Example:
```python
import atomicwrites
from pathlib import Path

def atomic_write_database(db_path: str, write_func: callable):
    """Atomically write to database using temp file + rename."""
    with atomicwrites.atomic_write(db_path, mode='wb', overwrite=True) as f:
        write_func(f)

def safe_file_exists(file_path: str) -> bool:
    """Check if file exists and is readable."""
    try:
        path = Path(file_path)
        return path.exists() and path.is_file()
    except (OSError, PermissionError):
        return False

def get_file_size(file_path: str) -> int:
    """Get file size in bytes, 0 if doesn't exist."""
    try:
        return Path(file_path).stat().st_size
    except (OSError, FileNotFoundError):
        return 0
```

Note: Database writes already use SQLite transactions in database.py, but this module provides additional atomicity guarantees for critical operations.

Create import workflow implementing LIB-01 with requirements from CONTEXT.md (reference-in-place, progress bar, failure reporting).

Follow RESEARCH.md Pattern 3 (Atomic Import with Progress Tracking).

Main function: import_directory(directory_path: str, is_soundcloud: bool = False) -> tuple[list, list]

Workflow:
1. Scan directory recursively for music files (.mp3, .flac, .m4a, .aac, .ogg)
2. For each file:
   a. Extract metadata using metadata.extract_metadata()
   b. Build organized_path using sanitizer.sanitize_path(album_artist, album, title, extension)
   c. Save to database using database.save_file_record(original_path, organized_path, is_soundcloud, metadata)
   d. Update progress bar (tqdm)
   e. On failure: append to failures list, continue with next file
3. After import completes, trigger duplicate detection by calling mark_all_duplicates() from Plan 04
4. Return (successes, failures) tuple

Progress tracking:
- Use tqdm with total=len(files) and desc="Importing"
- Default: show progress bar only
- Optional: detailed log mode (print each file being processed)

Failure handling:
- Collect all failures: list of tuples (file_path, error_message)
- Do NOT stop import on failure
- After completion, return failures for display

Reference-in-place:
- Store original_path as-is (absolute path to existing file)
- organized_path is derived from metadata, not actual file operation
- Do NOT copy, move, or symlink files

Duplicate detection integration (LIB-04):
- After import loop completes, call mark_all_duplicates() from src.library.duplicate
- Catch import errors (duplicate module may not exist in earlier execution waves)
- Update display_import_summary() to show duplicates found

Example structure:
```python
from pathlib import Path
from tqdm import tqdm
from src.library.metadata import extract_metadata, MetadataExtractionError
from src.library.sanitizer import sanitize_path
from src.library.database import save_file_record

SUPPORTED_FORMATS = ['.mp3', '.flac', '.m4a', '.aac', '.ogg']

def import_directory(directory_path: str, is_soundcloud: bool = False, verbose: bool = False) -> tuple[list, list]:
    """Import music files from directory into library."""
    directory = Path(directory_path)
    if not directory.exists() or not directory.is_dir():
        raise ValueError(f"Directory not found: {directory_path}")

    # Scan for music files
    files = []
    for ext in SUPPORTED_FORMATS:
        files.extend(directory.rglob(f"*{ext}"))

    successes = []
    failures = []

    with tqdm(total=len(files), desc="Importing", unit="file") as pbar:
        for file_path in files:
            try:
                # Extract metadata
                metadata = extract_metadata(str(file_path))

                # Build organized path
                extension = file_path.suffix
                organized_path = sanitize_path(
                    metadata['album_artist'],
                    metadata['album'],
                    metadata['title'],
                    extension
                )

                # Save to database (reference-in-place)
                file_id = save_file_record(
                    original_path=str(file_path.absolute()),
                    organized_path=organized_path,
                    is_soundcloud=is_soundcloud,
                    metadata_dict=metadata
                )

                successes.append(str(file_path))

                if verbose:
                    pbar.write(f"✓ {file_path.name}")

            except (MetadataExtractionError, Exception) as e:
                failures.append((str(file_path), str(e)))
                if verbose:
                    pbar.write(f"✗ {file_path.name}: {e}")

            finally:
                pbar.update(1)

    # Run duplicate detection after import completes (LIB-04)
    duplicates_count = 0
    try:
        from src.library.duplicate import mark_all_duplicates
        duplicates_count = mark_all_duplicates()
        if duplicates_count > 0 and verbose:
            print(f"\n⚠ Found {duplicates_count} duplicate file(s)")
    except ImportError:
        # Duplicate module not yet implemented (Plan 04 hasn't executed)
        pass

    return successes, failures

def display_import_summary(successes: list, failures: list, duplicates_count: int = 0):
    """Display import results summary."""
    print(f"\n=== Import Complete ===")
    print(f"✓ Successful: {len(successes)}")
    print(f"✗ Failed: {len(failures)}")

    if duplicates_count > 0:
        print(f"⚠ Duplicates: {duplicates_count}")

    if failures:
        print("\n=== Failures ===")
        for file_path, error in failures:
            print(f"  {file_path}")
            print(f"    → {error}")
```
