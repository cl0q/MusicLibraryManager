**LibraryMountContext (contexts/LibraryMountContext.tsx):**

Create the `ui/src/contexts/` directory if it doesn't exist.

Define mount state type:
```typescript
type MountState = "connected" | "disconnected" | "not_configured" | "loading";
```

Create context with provider and hook:

```typescript
interface LibraryMountContextValue {
  mountState: MountState;
  isLibraryAvailable: boolean;  // Convenience: true only when connected
  refreshMountState: () => Promise<void>;  // Manual refresh
}
```

**LibraryMountProvider:**

1. Initialize with `mountState: "loading"`
2. On mount:
   a. Call `get_library_config()` to check if configured
   b. If not configured: set state to `"not_configured"`
   c. If configured: call `check_library_connection()` to check current mount state
   d. Set initial state to `"connected"` or `"disconnected"` based on result
3. Subscribe to Tauri events:
   - Listen for `library-mount-changed` event via `import { listen } from "@tauri-apps/api/event"`
   - On event: parse payload and update mountState
   - Clean up listener on unmount
4. When state transitions to `"connected"`:
   - Dispatch a custom window event `library-reconnected` so LibraryBrowser can re-fetch tracks
   - This implements the locked decision: "When drive reconnects: auto-refresh library silently"
5. `refreshMountState()`: Re-check connection and config state. Used after settings changes.

**useLibraryMount hook:**
```typescript
export function useLibraryMount() {
  const context = useContext(LibraryMountContext);
  if (!context) throw new Error("useLibraryMount must be used within LibraryMountProvider");
  return context;
}
```

**Tauri event listening:**

Import `listen` from `@tauri-apps/api/event`. The backend emits events with `app_handle.emit("library-mount-changed", payload)`. The frontend listens with:

```typescript
const unlisten = await listen<string>("library-mount-changed", (event) => {
  const state = event.payload; // "Connected", "Disconnected", or "NotConfigured"
  setMountState(mapBackendState(state));
});
```

Map backend enum names to frontend state strings (backend uses PascalCase, frontend uses lowercase).

**Auto-refresh on reconnection:**

