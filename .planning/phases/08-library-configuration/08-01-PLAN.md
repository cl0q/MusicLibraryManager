**Database schema (schema.rs):**

Add Phase 8 migration (schema version 6). Create `app_config` table:

```sql
CREATE TABLE IF NOT EXISTS app_config (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
);
```

Add `PHASE8_SCHEMA_SQL` constant, `migrate_to_v6()` function, update `CURRENT_SCHEMA_VERSION` to 6, and add the v6 migration call in `initialize_schema()`.

**Config module (config/mod.rs, config/library.rs):**

Create `src-tauri/src/config/` directory with:

- `mod.rs`: Re-exports `LibraryConfig`
- `library.rs`: `LibraryConfig` struct with fields:
  - `root_path: Option<PathBuf>` (None if not configured)
  - `scan_folders: Vec<String>` (relative paths from root)
  - `download_destination: String` (relative path from root, default "00_Artist")
  - `library_id: Option<String>` (UUID, None if not configured)
  - `configured: bool`

Implement on `LibraryConfig`:
  - `load(conn: &Connection) -> Result<Self>`: Read from `app_config` table. If `library_root` key is empty, return unconfigured state. Parse `scan_folders` from JSON array string.
  - `save(&self, conn: &Connection) -> Result<()>`: Upsert `app_config` keys: `library_root`, `library_id`, `scan_folders` (as JSON array), `download_destination`, `library_configured`.
  - `resolve_path(&self, relative: &str) -> Option<PathBuf>`: If root_path is Some, join relative path. Return None if not configured.
  - `make_relative(&self, absolute: &Path) -> Result<String, String>`: Strip root_path prefix from absolute path, return as String with forward slashes.
  - `is_configured(&self) -> bool`: Returns self.configured

**Marker file structs:**

In `library.rs`, add:
- `MarkerFile` struct (Serialize/Deserialize): `version: u32`, `library_id: String`, `created_at: String`, `name: Option<String>`
- `verify_marker_file(path: &Path) -> Result<MarkerFile, String>`: Read and parse `mlm-library.json` at given path
- `create_marker_file(path: &Path, library_id: &str) -> Result<(), String>`: Write `mlm-library.json` with version 1, library_id, created_at (chrono::Utc::now), name None

**Cargo.toml:**

Add `uuid = { version = "1", features = ["v4", "serde"] }` to dependencies. (chrono already present)

**lib.rs:**

Add `pub mod config;` to module declarations.

**Important:** Use `INSERT OR REPLACE INTO app_config (key, value, updated_at) VALUES (?, ?, CURRENT_TIMESTAMP)` pattern for upserts. Do NOT use `INSERT OR IGNORE` as config values change.

**Create commands/library_config.rs with these Tauri commands:**

1. `select_library_folder(app_handle: tauri::AppHandle) -> Result<Option<String>, String>`:
   - Use `app_handle.dialog().file().blocking_pick_folder()` to show native OS folder picker
   - Note: Tauri v2 dialog `blocking_pick_folder()` returns `Option<FilePath>`. Handle the conversion to String.
   - Return the selected path as String, or None if user cancelled.

2. `get_subfolders(root_path: String) -> Result<Vec<String>, String>`:
   - List immediate subdirectories of `root_path` (non-recursive, directories only)
   - Filter out hidden directories (starting with `.`)
   - Return sorted Vec of directory names (not full paths, just names)
   - This enables the UI to show checkboxes for subfolder inclusion/exclusion

3. `configure_library(root_path: String, scan_folders: Vec<String>, download_destination: String) -> Result<(), String>`:
   - Validate root_path exists and is a directory
   - Validate root_path is writable (try creating a temp file, delete it)
   - Check for existing marker file at `root_path/mlm-library.json`:
     - If exists: read and use its library_id (connecting to existing library)
     - If not exists: generate new UUID v4 library_id, create marker file
   - Create LibraryConfig and save to database
   - Return Ok(()) on success

4. `get_library_config() -> Result<LibraryConfig, String>`:
   - Load and return current LibraryConfig from database
   - Used by frontend to check configuration state on startup

5. `check_library_connection() -> Result<bool, String>`:
   - Load LibraryConfig from database
   - If not configured, return false
   - If configured, check if root_path exists and is accessible (the directory exists means drive is mounted)
   - Return true if connected, false if drive not mounted

**Register in commands/mod.rs:**

Add `pub mod library_config;` and re-export the commands.

**Register in lib.rs:**

Add all 5 commands to `tauri::generate_handler![]` macro:
- `commands::library_config::select_library_folder`
- `commands::library_config::get_subfolders`
- `commands::library_config::configure_library`
- `commands::library_config::get_library_config`
- `commands::library_config::check_library_connection`

**Database path note:** Use `PathBuf::from("music_library.db")` for database connection, matching the existing pattern in other command files (startup.rs, commands/import.rs, etc.).

**Important:** The `select_library_folder` command needs `app_handle` parameter. In Tauri v2, commands receive `AppHandle` via `app_handle: tauri::AppHandle` parameter (Tauri auto-injects it). Verify the dialog API usage matches Tauri v2 plugin-dialog: the `DialogExt` trait from `tauri_plugin_dialog` provides `.dialog()` on AppHandle.
