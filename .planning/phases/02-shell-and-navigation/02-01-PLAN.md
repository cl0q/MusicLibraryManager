# Plan 02-01: Shell & Navigation

## Phase
02 — Shell & Navigation (maps to PLAN.md Phase 2)

## Goal
Full window layout with NavigationSplitView, MiniPlayer bar, collapsible ActivityPanel, and ⌘1-5 keyboard shortcuts. Every section navigable, Settings openable, UI skeleton complete for Phase 3 (Library Browser) to build on.

## Success Criteria
1. NavigationSplitView renders with 5-section sidebar + detail area
2. Sidebar keyboard shortcuts ⌘1-5 switch sections via CommandMenu
3. MiniPlayerView shows persistent 36px bar below content (empty state)
4. ActivityPanel toggles between collapsed (36px) and expanded (~284px)
5. ActivityPanel expanded shows Operations and Logs tabs (placeholder content)
6. Settings button in sidebar opens the Settings window
7. Detail area shows placeholder views for all 5 sections
8. Window respects min size (900×600) and default size (1200×800)
9. Three app states render correctly: loading, error, initialized
10. FocusedSceneValue pattern enables cross-scene keyboard shortcut wiring

## What Was Built

### Files Created
- `MLM/Views/MiniPlayer/MiniPlayerView.swift` — 36px persistent bar with play icon, "No track playing" text, progress bar placeholder, duration placeholder
- `MLM/Views/Activity/ActivityPanel.swift` — Collapsible panel with header bar (chevron + "Activity" + summary text), segmented picker for tabs, animated expand/collapse
- `MLM/Views/Activity/OperationsTab.swift` — Empty-state placeholder for download/sync/import operations
- `MLM/Views/Activity/LogsTab.swift` — Empty-state placeholder for real-time log stream

### Files Modified
- `MLM/Views/ContentView/ContentView.swift` — Major rework:
  - Added `FocusedValueKey` + `FocusedValues` extension for ⌘1-5 shortcut wiring
  - Restructured body to VStack: NavigationSplitView + separators + MiniPlayerView + ActivityPanel
  - Added `.focusedSceneValue(\.selectedSection, $selectedSection)` for CommandMenu binding
  - Added explicit `Hashable` conformance to `SidebarSection`
  - Improved error view with text centering and padding
- `MLM/Views/Sidebar/SidebarView.swift` — Settings button wired to `NSApp.sendAction(showSettingsWindow:)`, added ⌘, keyboard shortcut
- `MLM/App/MLMApp.swift` — Added `@FocusedBinding(\.selectedSection)`, added `CommandMenu("Navigate")` with `ForEach(SidebarSection.allCases)` and `.keyboardShortcut()`, replaced bare `Text("Settings")` with `SettingsPlaceholderView`

## Patterns Used
- **FocusedSceneValue** — ContentView publishes `$selectedSection` binding; MLMApp's CommandMenu reads it via `@FocusedBinding`. Standard SwiftUI pattern for command-to-view communication.
- **Solar theme tokens** — All colors, fonts, and spacing reference `Color.mlm*`, `MLMFont.*`, `MLMSpacing.*` constants from Phase 1.
- **Declarative state management** — No shared observable state needed for Phase 2; `@State` in ContentView + `@State` in ActivityPanel handle all local UI state.
