# Plan 03-01: Library Browser

## Phase
03 — Library Browser (maps to PLAN.md Phase 3)

## Goal
Full-featured library table with all columns, column sorting, search with debounce, Local/Remote tab switching, energy bars renderer, right-click context menu, and multi-select. Replaces the Library PlaceholderView with a real data-driven view backed by TrackRepository.

## Success Criteria
1. LibraryTable renders with columns: title, artist, album, format, bitrate, duration, genre, year, energy, date_added
2. Column sorting toggles ascending/descending on header click
3. FilterBar provides search (⌘F) with debounced query against title/artist/album
4. Local/Remote tab switcher shows correct counts and filters tracks accordingly
5. EnergyBars custom column renderer visualizes energyBucket (1–5) as colored bars
6. Right-click TrackContextMenu appears on track rows
7. Multi-select works with ⌘-click (toggle) and Shift-click (range)
8. Empty states shown for "no tracks" and "no search results"

## Files to Create
- `MLM/ViewModels/LibraryViewModel.swift` — `@Observable`, owns tracks, search, sort, tab state
- `MLM/Views/Library/LibraryView.swift` — Container: FilterBar + LibraryTable
- `MLM/Views/Library/LibraryTable.swift` — SwiftUI `Table` with all columns + sorting + selection
- `MLM/Views/Library/FilterBar.swift` — Search field + Local/Remote picker + action buttons
- `MLM/Views/Library/EnergyBars.swift` — 5-bar energy visualization for table column
- `MLM/Views/Library/TrackContextMenu.swift` — Context menu with placeholder actions

## Files to Modify
- `MLM/Views/ContentView/ContentView.swift` — Replace `.library` PlaceholderView with LibraryView

## Dependencies
- Phase 1 (complete) — DependencyContainer, TrackRepository, Track model, theme tokens
- Phase 2 (complete) — ContentView layout, SidebarSection routing, MiniPlayer + ActivityPanel

## Patterns
- `@Observable` ViewModel injected via `@Environment(\.container)` for database access
- Debouncer from Utilities for search
- Solar theme tokens throughout
- GRDB async reads via TrackRepository
