# Phase 5 — Track Detail & Playback

## Plan 05-01: Full playback pipeline, detail view, waveform, mini player integration

### Goal

Wire the complete playback pipeline: double-click a track → detail inspector opens → waveform renders → play/pause works → mini player updates. Spacebar global shortcut. LUFS gain compensation. Now-playing indicator in library table.

### Context

Phase 1 scaffolded `AudioPlayer.swift` (AVAudioEngine graph with gain node), `PlaybackViewModel.swift` (position timer, LUFS, waveform extraction), `TrackDetailView.swift`, `WaveformView.swift`, and `MetadataPanel.swift`. This plan verifies and hardens the existing scaffold, fills integration gaps, and completes the playback loop.

### Audio Pipeline Architecture

```
User: double-click row / context menu "Play" / spacebar
    ↓
ContentView.handleTrackDoubleClick(track) — or — PlaybackViewModel.togglePlayPause()
    ↓
PlaybackViewModel.playTrack(track)
    ├── Resolves path: configRepository.getLibraryRoot() + track.organizedPath
    ├── AudioPlayer.loadFile(at:) — opens AVAudioFile, reads format/length
    ├── AudioPlayer.applyLUFSCompensation(lufsI:) — calculates gain offset to -14 LUFS target
    ├── AudioPlayer.play() — scheduleSegment + playerNode.play()
    ├── Posts .playbackTrackDidChange + .playbackStateDidChange
    ├── Starts position timer (50ms poll)
    └── Task.detached: extractWaveformData(binCount: 200) → waveformData
    
UI Observers (all @Observable, no NotificationCenter needed for owned views):
    ├── MiniPlayerView — reads playbackVM.currentTrack, isPlaying, progress, formattedPosition/Duration
    ├── TrackDetailView — reads playbackVM via container, shows waveform + play/pause
    ├── LibraryTable — isNowPlaying(track) highlights current track in title column
    └── MLMApp CommandMenu — spacebar togglePlayPause when hasTrack

NotificationCenter (for decoupled observers):
    ├── .playbackTrackDidChange — userInfo: ["trackId": Int64]
    └── .playbackStateDidChange — userInfo: ["state": PlaybackState]
```
