<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete download flow from Remote view to Library with real-time progress feedback and context menu optimization.

Backend changes:
- download_tracks command with Tauri channel progress streaming
- download_status database updates on successful downloads
- download-complete event emission after batch completion

Frontend changes:
- Download action in context menu (Remote tracks only)
- Real-time download progress component
- Auto-refresh Remote view on download completion
  </what-built>

  <how-to-verify>
**Test 1: Single Track Download**

1. Start the app: `cd src-tauri && cargo tauri dev`
2. Navigate to Remote view (sidebar: Cloud icon)
3. Right-click any remote track
4. Verify:
   - Context menu appears instantly (feels immediate, no delay)
   - Download action appears at top of menu
   - Download action has download icon
5. Click "Download"
6. Verify:
   - Progress overlay appears in bottom-right corner
   - Track name displays correctly
   - Progress bar moves from 0% to 100%
   - Percent updates in real-time
7. Wait for download to complete
8. Verify:
   - Success toast appears: "Downloaded 1/1 tracks"
   - Progress overlay disappears
   - Remote view refreshes automatically
   - Track disappears from Remote view
9. Navigate to Library view
10. Verify:
    - Downloaded track appears in Library
    - Metadata is correct (artist, title, album)
    - Format column shows audio format (FLAC/AAC), not "Stream"

**Test 2: Multi-Track Batch Download**

1. In Remote view, select 3-5 tracks using Cmd/Ctrl+click
2. Verify: Selected tracks show blue highlight
3. Right-click on any selected track
4. Click "Download"
5. Verify:
   - Progress overlay shows "Downloading (1/5)", "(2/5)", etc.
   - Track name updates for each track in batch
   - Progress bar updates continuously
6. Wait for all downloads to complete
7. Verify:
   - Success toast: "Downloaded 5/5 tracks"
   - All selected tracks disappear from Remote view
   - All tracks appear in Library view with correct metadata

**Test 3: Context Menu Responsiveness**

1. In Remote view, rapidly right-click different tracks 5+ times
2. Verify:
   - Menu appears instantly every time (< 50ms perceived latency)
   - No flickering or re-rendering
   - Menu data (playlists, sync profiles) loads once, not on each click
3. In Library view, right-click a local track
4. Verify:
   - Context menu appears instantly
   - NO Download action (only for Remote tracks)
   - File actions (Reveal, Copy Path) appear
5. Switch back to Remote view
6. Right-click a remote track
7. Verify:
   - Download action appears
   - NO file actions (Reveal, Copy Path)

**Test 4: Download with Failures**

1. Disconnect from internet or use a track unlikely to exist on any source
2. In Remote view, select a track and click Download
3. Verify:
   - Progress overlay shows download attempt
   - After failure: error toast mentions "Check Downloads page"
   - Track remains in Remote view (download_status stays NULL)

**Test 5: Remote View Auto-Refresh**

1. Have Remote view open with 10+ tracks visible
2. Download 3 tracks from the middle of the list
3. Verify:
   - After download completes, Remote view refreshes
   - Downloaded tracks disappear
   - Remaining tracks stay in view
   - No duplicate tracks appear
   - Scroll position roughly maintained
  </how-to-verify>
