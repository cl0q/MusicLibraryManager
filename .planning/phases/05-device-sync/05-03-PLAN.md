**Core detection function:**
```rust
pub fn detect_rockbox_devices() -> Result<Vec<RockboxDevice>> {
    let mut devices = Vec::new();

    #[cfg(target_os = "macos")]
    {
        let volumes = PathBuf::from("/Volumes");
        if volumes.exists() {
            for entry in fs::read_dir(&volumes)? {
                let entry = entry?;
                let path = entry.path();
                if is_rockbox_device(&path) {
                    devices.push(create_device_info(path)?);
                }
            }
        }
    }

    #[cfg(target_os = "linux")]
    {
        for base in &["/mnt", "/media"] {
            let base_path = PathBuf::from(base);
            if base_path.exists() {
                scan_mount_base(&base_path, &mut devices)?;
            }
        }
    }

    #[cfg(target_os = "windows")]
    {
        // Scan drive letters A: through Z:
        for letter in b'A'..=b'Z' {
            let drive = format!("{}:\\", letter as char);
            let path = PathBuf::from(&drive);
            if path.exists() && is_rockbox_device(&path) {
                devices.push(create_device_info(path)?);
            }
        }
    }

    Ok(devices)
}
```

**Helper functions:**

1. `is_rockbox_device(path: &Path) -> bool`
   - Check for .rockbox directory marker
   - Return path.join(".rockbox").is_dir()

2. `create_device_info(mount_point: PathBuf) -> Result<RockboxDevice>`
   - Extract device name from mount point
   - Get available space via get_available_space
   - Return RockboxDevice struct

3. `get_available_space(mount_point: &Path) -> Result<u64>`
   - Platform-specific disk space query
   ```rust

   {
       use std::os::unix::fs::statvfs;
       let stats = statvfs(mount_point)?;
       Ok(stats.f_bavail * stats.f_bsize)
   }

   #[cfg(windows)]
   {
       use std::os::windows::fs::MetadataExt;
       // Use GetDiskFreeSpaceEx via winapi or similar
       // Fallback: return u64::MAX if cannot determine
   }
   ```

4. `scan_mount_base(base: &Path, devices: &mut Vec<RockboxDevice>) -> Result<()>`
   - Recursive helper for Linux /mnt and /media scanning
   - Check each subdirectory for .rockbox marker

**Note on M3U8 format:**
Research recommended hls_m3u8 crate but that's for HLS streaming (HTTP Live Streaming). For Rockbox, we need simple M3U8 format with #EXTM3U header and relative file paths. Hand-roll this—it's simpler than the research suggested.

**Core generation function:**
```rust
pub fn generate_m3u8(
    playlist_name: &str,
    tracks: &[Track],
    profile_folder: &Path,
) -> Result<String> {
    let mut lines = Vec::new();

    // M3U8 header
    lines.push("#EXTM3U".to_string());

    for track in tracks {
        // #EXTINF with duration and artist - title
        let duration = track.duration.unwrap_or(0);
        let extinf = format!(
            "#EXTINF:{},{} - {}",
            duration,
            track.artist,
            track.title
        );
        lines.push(extinf);

        // Relative path from profile root to track file
        // Profile structure: Artist/Album/Track.m4a
        let relative_path = format!(
            "{}/{}/{}.m4a",
            sanitize_filename(&track.artist),
            sanitize_filename(&track.album),
            sanitize_filename(&track.title)
        );
        lines.push(relative_path);
    }

    Ok(lines.join("\n"))
}
```

**Helper function:**

**File writing function:**
```rust
pub fn write_playlist_file(
    playlist_path: &Path,
    content: &str,
) -> Result<()> {
    let file = File::create(playlist_path)
        .context("Failed to create playlist file")?;

    let mut writer = BufWriter::new(file);
    writer.write_all(content.as_bytes())?;
    writer.flush()?;

    Ok(())
}
```

**Rockbox playlists directory structure:**
Playlists should be written to: `{profile_folder}/Playlists/{playlist_name}.m3u8`

Add convenience function:
```rust
pub fn write_profile_playlist(
    profile_folder: &Path,
    playlist_name: &str,
    tracks: &[Track],
) -> Result<()> {
    let playlists_dir = profile_folder.join("Playlists");
    std::fs::create_dir_all(&playlists_dir)?;

    let content = generate_m3u8(playlist_name, tracks, profile_folder)?;
    let playlist_path = playlists_dir.join(format!("{}.m3u8", playlist_name));

    write_playlist_file(&playlist_path, &content)
}
```
