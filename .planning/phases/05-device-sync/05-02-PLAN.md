pub struct TranscodeCache {
    cache_dir: PathBuf,

    }
}

**Core methods:**

1. `get_cache_path(&self, track_id: i64, original_path: &Path) -> PathBuf`
   - Deterministic cache filename: `{track_id}.m4a`
   - Simple approach: track_id uniquely identifies cached transcode
   - Return: cache_dir.join(format!("{}.m4a", track_id))

2. `exists(&self, track_id: i64, original_path: &Path) -> bool`
   - Check if cache file exists and is valid (size > 0)
   - Return self.get_cache_path(track_id, original_path).exists()

3. `link_to_profile(&self, cache_path: &Path, profile_path: &Path) -> Result<()>`
   - Platform-specific file linking:
   ```rust
   #[cfg(unix)]
   {
       // Try hardlink first (same filesystem, saves space)
       if let Ok(_) = std::fs::hard_link(cache_path, profile_path) {
           return Ok(());
       }
       // Fallback to copy if hard_link fails (cross-filesystem)
       copy_with_buffering(cache_path, profile_path)?;
   }

   #[cfg(not(unix))]
   {
       // Windows: always copy (symlinks need admin rights)
       copy_with_buffering(cache_path, profile_path)?;
   }
   ```

4. `copy_with_buffering(src: &Path, dst: &Path) -> Result<()>`
   - Helper function using BufReader/BufWriter for efficient copying
   - Pattern from RESEARCH.md: 64KB buffer, fixed memory usage
   ```rust
   let mut reader = BufReader::new(File::open(src)?);
   let mut writer = BufWriter::new(File::create(dst)?);
   const CHUNK_SIZE: usize = 65536;
   let mut buffer = [0u8; CHUNK_SIZE];
   loop {
       let n = reader.read(&mut buffer)?;
       if n == 0 { break; }
       writer.write_all(&buffer[..n])?;
   }
   writer.flush()?;
   ```

5. `compute_checksum(&self, path: &Path) -> Result<String>`
   - SHA256 checksum for sync state tracking
   - Return hex string of hash
   ```rust
   let mut file = File::open(path)?;
   let mut hasher = Sha256::new();
   let mut buffer = [0u8; 65536];
   loop {
       let n = file.read(&mut buffer)?;
       if n == 0 { break; }
       hasher.update(&buffer[..n]);
   }
   Ok(format!("{:x}", hasher.finalize()))
   ```

6. `build_profile_path(&self, profile_folder: &Path, track: &Track) -> Result<PathBuf>`
   - Mirror library structure: Profile/Artist/Album/Track.m4a
   - Use sanitize_filename from metadata module for FAT32 compatibility
   - Return profile_folder.join(artist).join(album).join(format!("{}.m4a", title))
   - Create parent directories if needed
