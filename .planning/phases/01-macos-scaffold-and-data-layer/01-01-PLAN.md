# Plan 01-01: macOS Project Scaffold + Core Data Layer

## Phase
01 — macOS Scaffold + Core Data Layer (combines PLAN.md Phase 0 + 1)

## Goal
Create a buildable macOS SwiftUI project with GRDB-backed database sharing the exact same SQLite schema as the Tauri app. App launches, database creates all tables, core models can CRUD via repositories.

## Success Criteria
1. Xcode project compiles targeting macOS 14+ (Sonoma)
2. SPM resolves GRDB dependency
3. App launches with SwiftUI lifecycle (@main)
4. DependencyContainer registers all services via @Environment
5. DatabaseManager opens/creates database with GRDB connection pool
6. All 17 schema migrations ported as GRDB DatabaseMigrator steps
7. Core models (Track, Playlist, SyncProfile, Album, Source) map to existing DB tables
8. All repositories (Track, Playlist, Sync, Album, Source, Analysis, Config) implement basic CRUD
9. Solar color theme tokens defined (Colors.swift, Typography.swift, Spacing.swift)
10. Entitlements configured (network, file access, Keychain)
11. Database is the EXACT SAME file as the Tauri app — schema parity verified

## Plans

### Plan A: Xcode Project + SPM + Entitlements + SwiftUI Entry
- Create `macos-app/MLM/` directory structure per PLAN.md §2
- Create `Package.swift` with GRDB dependency
- Create `MLMApp.swift` (@main entry point)
- Create `AppDelegate.swift` for NSApplicationDelegate lifecycle
- Create `DependencyContainer.swift` with protocol-based DI
- Create `MLM.entitlements` (network, file access, Keychain)
- Create Solar theme files: `Colors.swift`, `Typography.swift`, `Spacing.swift`

### Plan B: DatabaseManager + Migrations
- Create `DatabaseManager.swift` with GRDB connection pool
- Port all 17 schema versions as GRDB `DatabaseMigrator` steps
- Create `Schema.swift` with table/column constants
- Verify schema parity with Tauri app's `001_initial_schema.sql` + v14-v17

### Plan C: Models + Repositories
- Create all model structs: Track, Playlist, SyncProfile, Album, Source, etc.
- Create all repositories with basic CRUD operations
- Create `SearchService.swift` stub for FTS5
- Create `ConfigRepository.swift` for app_config key-value store

## Dependencies
- None (milestone foundation)

## Risks
- GRDB version compatibility with macOS 14+ — mitigated by using latest stable
- Schema drift between Tauri and macOS apps — mitigated by porting from exact SQL source
