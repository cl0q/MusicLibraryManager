Update `ui/src/types/events.ts`:
- Extend DownloadProgressEvent type to include detailed fields from locked decisions:
  - Existing fields: track_id, track_name, status, progress, error (keep these)
  - NEW fields to add:
    - source: string (e.g., "Spotify", "SoundCloud", "Local")
    - current_step: string (e.g., "Downloading FLAC", "Transcoding to MP3", "Importing metadata")
    - speed: string (e.g., "2.4 MB/s")
    - eta: string (e.g., "30s remaining")
    - file_size: string (e.g., "45.2 MB")

Complete type:
```typescript
export type DownloadProgressEvent = {
  track_id: string;
  track_name: string;
  status: "queued" | "downloading" | "transcoding" | "completed" | "failed";
  progress: number;
  error?: string;
  source: string;
  current_step: string;
  speed?: string;
  eta?: string;
  file_size?: string;
};
```

Create `ui/src/hooks/useDownloadQueue.ts`:
- Export useDownloadQueue() hook:
  - useState for downloads: Map<string, DownloadProgressEvent> (key: track_id, value: event from types/events.ts)
  - useState for queueStatus: { total: number, completed: number, failed: number, in_progress: number }

  - useEffect to fetch initial queue status on mount:
    - Call invokeTauriCommand("get_retry_queue_status")
    - Parse response and set queueStatus state

  - useEffect to listen for download:progress events:
    - Import listen, UnlistenFn from @tauri-apps/api/event
    - Setup listener for "download:progress" event
    - On event received: update downloads Map with track_id -> event.payload
    - Update queueStatus counts based on event.payload.status
    - Return cleanup function calling unlisten()

  - Function handleRetryFailed():
    - Call invokeTauriCommand("retry_failed_downloads")
    - On success: show toast.success("Retrying failed downloads")
    - On error: show toast.error("Failed to retry downloads")

  - Return { downloads, queueStatus, handleRetryFailed }

IMPORTANT: Always clean up event listeners on unmount to prevent memory leaks. Update downloads Map immutably: new Map(downloads).set(track_id, event).
  </action>
