Create `ui/src/hooks/useTauriCommand.ts`:
- Generic hook for invoking Tauri commands with error handling
- Function signature: `async function invokeTauriCommand<T>(cmd: string, payload?: Record<string, unknown>): Promise<{ ok: boolean; data?: T; error?: string }>`
- Wraps @tauri-apps/api/core invoke() in try/catch
- Returns { ok: true, data: T } on success, { ok: false, error: string } on failure
- Example usage: `const result = await invokeTauriCommand<Track[]>("search_library", { query: "test" })`

Create `ui/src/hooks/useTauriEvents.ts`:
- Export useActivityFeed() hook:
  - useState for activities: ActivityEvent[] (from types/events.ts)
  - useEffect to listen() on "library:activity" event from @tauri-apps/api/event
  - Prepends new events to array, keeps last 50 items
  - Returns cleanup function calling unlisten()
  - Returns activities array

- Export useDownloadProgress() hook:
  - useState for downloads: Map<string, DownloadProgressEvent> keyed by track_id
  - useEffect to listen() on "download:progress" event
  - Updates map with latest progress for each track_id
  - Returns downloads Map

IMPORTANT: Always return cleanup function in useEffect that calls unlisten() to prevent memory leaks on unmount.

Pattern:
```typescript
useEffect(() => {
  let unlistenFn: UnlistenFn | null = null;
  listen("event:name", handler).then(unlisten => { unlistenFn = unlisten; });
  return () => { unlistenFn?.(); };
}, []);
```
