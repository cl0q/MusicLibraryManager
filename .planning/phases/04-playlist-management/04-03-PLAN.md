Add smart playlist views to PHASE4_SCHEMA_SQL constant (after table definitions):

1. **smart_playlist_recently_added view:**
   - SELECT id, artist, album, title, date_added FROM tracks
   - WHERE date_added &gt;= datetime('now', '-30 days')
   - ORDER BY date_added DESC
   - Comment: "Recently Added: tracks added in last 30 days, sorted newest first"

2. **smart_playlist_most_played view:**
   - SELECT t.id, t.artist, t.album, t.title, COALESCE(ts.play_count, 0) AS play_count
   - FROM tracks t LEFT JOIN track_stats ts ON t.id = ts.track_id
   - ORDER BY play_count DESC
   - LIMIT 100
   - Comment: "Most Played: top 100 tracks by play count (populated in Phase 5 via Rockbox stats)"
   - Note: track_stats table will be added in Phase 5; view is forward-compatible
