Add `refresh_mirrored_playlist` to `src-tauri/src/database/playlist.rs`:

1. **refresh_mirrored_playlist:**
   - Parameters: conn (&amp;Connection), playlist_id (i64), source_tracks (Vec&lt;(i64, usize)&gt;) where tuple is (track_id, source_position_index)
   - Use transaction: `conn.transaction()?`
   - Query existing tracks: SELECT track_id, position FROM playlist_tracks WHERE playlist_id = ?
   - Build BTreeMap&lt;i64, String&gt; of existing (track_id -&gt; position)
   - For each (track_id, source_idx) in source_tracks:
     - If track_id NOT in existing:
       - Compute fractional position based on source_idx:
         - Find tracks at source_idx-1 and source_idx in local playlist
         - Call position_between(prev_position, next_position) to insert at correct spot
         - If source_idx is 0, insert before first track
         - If source_idx is greater than local size, append to end
       - INSERT INTO playlist_tracks (playlist_id, track_id, position) VALUES (?, ?, ?)
     - If track_id already in existing: skip (preserve existing position, do NOT update)
   - Commit transaction
   - Include test:
     - Import playlist [A, B, C]
     - Manually reorder to [B, A, C]
     - Refresh with source [A, B, D, C] (D is new at index 2)
     - Verify result: [B, A, D, C] (manual reordering preserved, D inserted at source position)

Algorithm for position computation:
- Map source_idx to local fractional position by finding neighbors in existing tracks
- Use position_between to generate position between neighbors
- Preserve gaps left by manual reordering (don't fill gaps)

Include unit tests covering:
- Add-only: track removed from source does not remove locally
- Position insertion: new track inserted at source position relative to existing tracks
- Manual reordering preserved: existing tracks keep their positions
