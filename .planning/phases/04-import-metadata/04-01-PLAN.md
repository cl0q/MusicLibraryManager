# Plan 04-01: Import & Metadata

## Phase
04 — Import & Metadata (maps to PLAN.md Phase 4)

## Goal
Complete the import pipeline: scan directories for audio files, extract metadata via AVFoundation, generate FAT32-safe organized paths, batch-insert tracks into the database, present a first-run wizard for initial library setup, and provide a Settings panel for re-scanning. Wire cross-view refresh so imported tracks appear in the Library table immediately.

## Status
Most implementation was shipped during Phase 1 (scaffold). This plan addresses the **integration gaps** that remain:
1. Post-import refresh notification — LibraryView does not reload after imports triggered from FirstRunWizard or Settings
2. SettingsView wrapper — Settings scene needs a proper container for future expansion (Phase 17)

- `MLM/App/MLMApp.swift` — Settings scene uses SettingsView instead of bare LibrarySetupView

## Integration Gap: Post-Import Refresh
**Problem:** LibraryView's `.task` modifier fires once on mount. When the FirstRunWizard imports tracks (behind the overlay) or Settings triggers a re-scan, the library table shows stale data.
**Solution:** `NotificationCenter` with `.libraryDidImport`. ImportViewModel posts after successful import → LibraryView observes and calls `loadTracks()`.
