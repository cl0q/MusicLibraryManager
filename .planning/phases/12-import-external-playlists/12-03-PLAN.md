<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 1: Verify playlist import flow end-to-end</name>
  <what-built>
    - Rust backend: import_playlist_command that parses M3U/JSON files, fuzzy-matches tracks against library, creates playlist
    - Frontend: ImportModal with file picker, name input, match preview (matched count / unmatched list), confirm button
    - "Import" button in PlaylistList triggers the modal
  </what-built>
  <how-to-verify>
    **Setup:**
    1. Start the app with `cd ui && npm run dev` (or cargo tauri dev)
    2. Navigate to the Playlists page

    **Test A — M3U import:**
    1. Create a test .m3u file with 3-5 tracks that exist in your library.
       Example content:
       ```
       #EXTM3U
       #EXTINF:180,Artist Name - Track Title
       /path/to/track.mp3
       ```
    2. Click the "Import" button on the Playlists page
    3. Verify: Import dialog opens
    4. Click "Browse" — verify native OS file picker appears, filtered to .m3u/.m3u8/.json
    5. Select your test .m3u file
    6. Verify: file name appears in the dialog, playlist name auto-fills from filename
    7. Optionally edit the playlist name
    8. Click "Preview Matches"
    9. Verify: MatchPreview shows matched count, unmatched count, match rate %
    10. Verify: Unmatched tracks (if any) listed with "No match" label
    11. Click "Create Playlist (N tracks)"
    12. Verify: Modal closes, playlist appears in the Playlists list
    13. Click the new playlist — verify it contains the matched tracks

    **Test B — Spotify JSON import:**
    1. Create a test .json file with the Spotify export format:
       ```json
       {"tracks":[{"artists":[{"name":"Artist"}],"name":"Track Title","duration_ms":200000}]}
       ```
    2. Repeat steps 2–13 from Test A with the .json file

    **Test C — No match case:**
    1. Create a playlist file with tracks that do NOT exist in the library (made-up artists/titles)
    2. Import it — verify: "No tracks matched" message, Create button is disabled

    **Test D — Cancelled dialog:**
    1. Click "Import", click "Browse", then cancel the file picker
    2. Verify: dialog stays open with no file selected (no crash)
  </how-to-verify>
  <resume-signal>Type "approved" if all 4 tests pass, or describe any issues found</resume-signal>
