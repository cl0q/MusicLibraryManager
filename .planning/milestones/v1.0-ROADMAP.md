# Milestone v1.0: MVP

**Status:** SHIPPED 2026-02-05
**Phases:** 1-7
**Total Plans:** 38

## Overview

This roadmap transformed the unreliable streaming2ipod system into a production-grade music library manager that aggregates from Spotify, Apple Music, SoundCloud, and local files. The journey started with atomic file operations and metadata foundations (Phase 1), proved download infrastructure with single-source reliability (Phase 2), expanded to multi-source aggregation with deduplication (Phase 3), implemented playlist management with order preservation (Phase 4), delivered device sync to Rockbox iPod (Phase 5), wrapped everything in a Tauri + React desktop UI (Phase 6), and concluded with enhancements for quality and usability (Phase 7).

## Milestone Summary

**Decimal Phases:** None (no urgent insertions needed)

**Key Decisions:**
- Rust for core logic (performance, reliability, single binary)
- Tauri for UI (web flexibility + Rust backend, small binaries)
- 248kbps AAC target (matches SoundCloud Go+ quality)
- Fractional indexing for playlist ordering (O(1) reorder operations)
- SHA256 checksums for sync state (industry standard)
- PKCE OAuth 2.1 for all OAuth flows (security best practice)
- Best-effort fingerprinting (failures don't block import)

**Issues Resolved:**
- Unreliable streaming2ipod system replaced with atomic operations
- Lack of transparency solved with real-time progress events
- Cross-source deduplication prevents duplicate downloads
- Playlist order preserved through all operations

**Issues Deferred:**
- Apple Music integration (deferred to v2)
- Multiple device profiles (deferred to v2)
- Background/scheduled sync (deferred to v2)

**Technical Debt Incurred:**
- Hardcoded database path (acceptable for single-user desktop app)
- Hardcoded "default" user_id for source creation
- Test-only import missing in playlist_gen.rs (1-line fix)
