Menu bar & keyboard — Tier 3 pattern catalogue

What this is: (a) the complete redesigned menu bar, every menu drawn open with every item, shortcut and separator, plus the Dock menu, each with a “Was → Now” line; (b) the complete keyboard map and what happens to each of the 52 shortcut entries of today’s app; (c) what double-click and Return do on every kind of row; (d) keys in sheets, text fields and lists. Press A to see IDs, C to comment on a menu, an item or a table row.

Decisions: DEC-038 (menu bar: MLM · File · Edit · View · Track · Playback · Library · Go · Window · Help), DEC-009 (space bar), DEC-047 (arrow keys), DEC-008 (Return / double-click), DEC-041 (Undo), DEC-006/007 (Queue ⌥⌘U, Info ⌘I). THOUGHTS §4.2, §4.3.

Item IDs: .E0x = numbered in the inventory today (also when the item moved to another menu — it keeps its old ID), .N0x = not numbered there: new, or system-provided and now specified.

(a) The menu bar

Menu bar DEC-038

Ten menus. Track is new: every command that acts on the selection has a menu item there, so it can be found, shows its shortcut, and is enabled or disabled honestly. Navigate becomes Go. Every item is driven by the focused main window (FocusedValue): with Settings or the Activity window in front, selection commands are disabled, never silently dead.

MLMFileEditViewTrackPlaybackLibraryGoWindowHelp
  • Contextual titles: items name their subject where that helps — Undo Add to “Warm-up”, Refresh from SoundCloud, Shuffle All Tracks, Remove from “Warm-up”, Hide Sidebar / Show Sidebar.
  • Disabled, not hidden: unlike context menus, menu-bar items never disappear — a command that can’t run now is greyed, so the menu bar is a stable map.
  • No library open (picker, loading, failure): File ▸ New Library…, Open Library…, Open Recent, MLM ▸ Settings…, Window ▸ Activity and Help work; everything else is disabled.

The space-bar rule K-LIB-SPACE DEC-009

Space previews what is selected; when there is nothing to preview it is Play/Pause. One setting switches it (variant C of DEC-009, default A). Full design and a working preview: player.html, try it on library.html.

SituationSpace does
One playable track selected in a focused list (tracks, queue, recommendations, similar, review versions)Preview it from its hot spot. The playing track pauses and keeps its position; the queue is untouched.
A preview is runningEnd the preview and resume what was playing. Esc does the same; ↑/↓ move the preview with the selection; ←/→ seek ±5 s; ↩ plays the track for real.
Nothing selected, or focus is in the sidebar, a grid of cards, or on the playerPlay/Pause the main playback.
Several tracks selectedNothing plays. Status bar: Space previews one track. Select a single track.
The selected track is Not downloaded / Download failedNothing plays. Status bar: Can’t preview — not downloaded. Press ⌘D to download.
The selected track’s file is missingStatus bar: Can’t preview — file missing.
The drive is not connectedStatus bar: Can’t preview — “Lexxar” is not connected.
A text field has focus (search, rename, Info, a sheet)Types a space. Never playback.
A button or checkbox has keyboard focusPresses it (system behaviour).
Settings ▸ General ▸ Space bar = “Always Play/Pause”Always Play/Pause; Preview is ⌥Space and stays in the Track menu.
