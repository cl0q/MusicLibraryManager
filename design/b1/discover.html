Recommendations: click a row, then ↑/↓ · Space preview in the toolbar player · K Keep · ⌫ Dismiss · ⌘Z or the status-bar Undo brings the row back · ⌘-/⇧-click several rows → selection bar with bulk Keep / Dismiss · right-click a row · drag a row onto a sidebar playlist (keeps it and adds it) · Find Recommendations… · switch Drive → Not connected: preview is unavailable and Dismiss is disabled with the reason.

Reels: scope bar → Reels. Select reels (⌘-click for several, ⌫ = Delete Reel…), click a keyframe, press Use on a guess, click the text fragments, Download on a result (Queued → Downloading… → In library), Add to Playlist. Similar: discover.html#similar (also reached from Info ▸ Audio ▸ Show All and from every track menu ▸ Find Similar); the toolbar Back button returns to Recommendations.

States (the switcher jumps to the view the state belongs to): Empty / Loading / Error → Recommendations (in Reels “Empty” = no reels yet) · Identifying / Not identified / No results / No internet → Reels · Not analysed / No sources → Similar (Loading, Error, No internet, Empty also change its Online section). Decisions: DEC-029, DEC-030, DEC-016, DEC-039, DEC-041, DEC-044.
