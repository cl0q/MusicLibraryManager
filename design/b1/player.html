Player and Space-bar preview — Tier 1

Try: click a row, press Space → the toolbar player switches to Preview (waveform, starts at the hot spot, the playing track pauses) · ↑/↓ moves the preview with the selection · Space or Esc ends it and resumes · Return plays for real (on a “Not downloaded” row it starts the download; on “File missing” it offers Locate…) · click the cover in the player (large cover) and the speaker (volume).

State switcher: puts the live toolbar player into each state. Drive → Not connected: the player says so; switch back and the status bar offers Resume. Variant B (DEC-010): the preview is a bar above the status bar and the toolbar keeps the paused track — press Space again to compare.

Every state is also drawn as a static block below the window. Decisions: DEC-009 (Space), DEC-010 (where the preview shows), DEC-045 (skip unplayable), DEC-047 (arrow keys seek only while previewing).

Space-bar rules K-LIB-SPACE DEC-009

Space previews what is selected; when there is nothing to preview it is Play/Pause. One setting switches it to “always Play/Pause”.

SituationSpace does
One local track selected in any list (tracks, queue, similar, recommendations)Preview it from its hot spot (the analysed drop, otherwise 0:30). The playing track pauses and keeps its position. The queue is untouched.
A preview is runningEnd the preview and resume what was playing, where it was. Esc does the same.
A preview is running, then ↑ / ↓The preview moves with the selection (each track from its own hot spot).
A preview is running, then ← / →Seek ±5 s inside the preview. Outside a preview the arrows belong to the focused control; seeking the main track is ⌥⌘← / ⌥⌘→ (DEC-047).
A preview is running, then ReturnPlay that track for real from the previewed position; the rows after it become the queue. The preview ends.
Nothing selected, or focus is in the sidebar / on the playerPlay/Pause the main playback.
Several tracks selectedNothing plays. Status bar: Space previews one track. Select a single track.
The selected track is Not downloaded / Download failedNothing plays. Status bar: Can’t preview — not downloaded. Press ⌘D to download.
The selected track’s file is missingStatus bar: Can’t preview — file missing.
The drive is not connectedStatus bar: Can’t preview — “Lexxar” is not connected.
A text field has focus (search, rename, Info)Types a space. Never playback.
An online result is selected (Search ▸ Online, Similar ▸ Online)Preview a 30 s stream; same player state, label Preview · from YouTube.
Settings ▸ General ▸ Space bar: Previews the selected trackDefault — the rows above. Choosing Plays or pauses makes Space always Play/Pause and moves the preview to ⌥Space. Settings
Media key ⏯, Playback ▸ Play/Pause, Dock menuAlways Play/Pause, whatever is selected.
