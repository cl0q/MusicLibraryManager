Add menu, Add from Link and Import Playlist from Source — Tier 2

Open a flow:

Then try: with a sheet open, use State in the review bar — every state changes what the open sheet shows (Empty · Loading · Error = the source didn’t answer · Sign-in expired found mid-way · Private · Tool missing · Queued behind another import). In Add from Link the three example links switch between a single track, a track that is already in the library and a playlist link (which hands over to the import sheet, step 2). In Import: pick a source on the left (Spotify shows Sign-in expired · Reconnect in place), click a playlist (one marked Already imported shows the re-import consequence), change All · First n · Random n, toggle Download now / Keep linked to SoundCloud, then Next → Import: the sheet closes and the status bar confirms.

Replaces the Sources sidebar section (V-SRC) and the separate import window (W-REMOTE). Accounts live in Settings ▸ Sources; the result of an import lives on the playlist (playlists.html#detail) and in Activity. A second import is queued, never rejected. Decisions: DEC-004, DEC-018, DEC-026, DEC-023, DEC-044. Flows F-05, F-06, F-20.

Refresh from Sources P-ADDMENU.N08 was V-SRC.E04f “Sync”

What it does: for every connected source, pulls newly liked tracks into All Tracks as Not downloaded and refreshes the account playlists that are linked. It never removes anything and never downloads by itself (unless “Download new tracks automatically” is on in Settings ▸ Sources). Sources whose sign-in expired are skipped and reported.

Where the result shows: status bar at the start and the end; Activity ▸ Running while it works; Activity ▸ Recent afterwards (kept across relaunch).

Browser sign-in hand-off S-SRC-OAUTH

MLM opens the source’s sign-in page in the default browser. While it waits it says so, in the place that asked (import sheet, Add from Link, Settings ▸ Sources, Activity). Outcomes: success → the place continues, status bar Spotify connected · cancelled → back to Sign-in expired · Reconnect · no answer for 5 minutes → Sign-in wasn’t finished · Try Again. No raw token or HTTP text.

Keychain permission A-SRC-KEYCHAIN system dialog

A macOS dialog, not MLM copy — it can appear after an update when MLM reads a saved sign-in.
