Search — one field, one behaviour — Tier 1

Try: type in the toolbar search field (or ⌘F): the current view filters in place, a scope bar appears under the toolbar, the availability counts follow · click the empty field for suggestions (recent searches, artist: genre: is: …) · remove a token with ✕ · switch the scope to Library (grouped results, Show all) or Online (sources answer one after another; Preview, Download) · type something that matches nothing → escalation buttons · Esc clears.

Links: — or paste any https://… into the field: a suggestion row appears instead of results.

The State switcher fills the field with an example for each state. Decisions: DEC-017 (always filter in place; scopes for wider), DEC-018 (links), DEC-013 (no source-as-album rows). The dead “universal search” panel (S-SEARCH-UNIVERSAL) is merged into this field.
