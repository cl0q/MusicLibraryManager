MLM — B1 design packet

Every screen, flow and interaction of MLM, rethought. Read THOUGHTS.md first (principles, information architecture, interaction model, decision log, questions), then walk the mockups. Start with All Tracks — the sidebar of every main-window page navigates to the others.

How to review

DoHow
See what an element is and whyPress A (Annotate). Every annotated element gets its ID badge; hover shows what it is, the decision behind it (DEC-… → THOUGHTS.md §8) and the SwiftUI API that would build it.
Leave a note on an elementPress C (Comment), click the element, type, Save (⌘↩). Notes are kept in this browser per page. Elements with a note get an orange badge.
Review your notesPress N for the notes panel of the page. Export feedback copies and downloads Markdown grouped by screen → element ID.
Export everything collects the notes of every page into one Markdown file (clipboard + download). Send me that file — or fill in FEEDBACK.md by hand.
Switch states and variantsThe bar at the top of each page: State (empty, loading, error…), Variant (V-FOLD/A, ★ = recommended), Drive (walk the whole app with “Lexxar” not connected), Light/Dark.
Use the mock like the appTables: click, ⇧/⌘-click, ↑↓, Space = preview, Return/double-click = play, ⌘I = Info, right-click = context menu. Sidebar, toolbar buttons, menus, sheets and alerts are clickable.

Glass is approximated with backdrop-filter; icons are simple stand-ins for SF Symbols. See README.md for all known approximations and COVERAGE.md for the inventory-ID → mockup map.
